# Cahier des charges

Plateforme RH destinée aux entreprises et à leurs salariés. Elle centralise les documents administratifs, la paie documentaire, le temps, les absences, les frais et les échanges avec le cabinet comptable.

Principe : un espace entreprise, un espace personnel sécurisé par salarié, et des espaces d'échange avec les interlocuteurs de l'entreprise. Le produit remplace une partie des échanges faits aujourd'hui par e-mail, papier ou outils dispersés. Ce n'est pas un simple gestionnaire de fichiers.
