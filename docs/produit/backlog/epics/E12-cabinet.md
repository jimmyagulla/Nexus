# E12 — Cabinet comptable

Relation distincte du coffre RH. Le cabinet voit les échanges qui lui sont destinés et rien d'autre.

| Story                                           | Priorité | Besoin       |
| :---------------------------------------------- | :------- | :----------- |
| [E12-US01](../us/E12-US01-connexion-cabinet.md) | 5        | Périphérique |
| [E12-US02](../us/E12-US02-echanges-cabinet.md)  | 5        | Périphérique |

Contrats possédés : connexion cabinet, échange cabinet.

Un échange n'est pas un document de coffre. Le révoquer ferme les nouveaux accès et masque les échanges au cabinet.
