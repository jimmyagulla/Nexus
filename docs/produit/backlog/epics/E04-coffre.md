# E04 — Coffre documentaire

Chaque fichier du coffre est un document : salarié propriétaire, catégorie, auteur, date, statut, droits. Le bulletin et l'échange cabinet ne se déposent pas par le formulaire général.

| Story                                          | Priorité | Besoin   |
| :--------------------------------------------- | :------- | :------- |
| [E04-US01](../us/E04-US01-coffre-employeur.md) | 1        | Critique |
| [E04-US02](../us/E04-US02-depot-salarie.md)    | 2        | Fort     |

Contrat possédé : document de coffre.

Catégories employeur : Contrat de travail, Avenant, Document mutuelle, Attestation, Document administratif, Courrier RH, Autre. Bulletin de salaire est réservé à E05-US01.

Catégories salarié : Arrêt maladie, Justificatif, Document administratif, Autre document demandé.

E04-US01 livre la consultation salarié. E04-US02 ajoute seulement le dépôt par le salarié sur cet écran.
