# 04 — Coffre documentaire et bulletins

Le coffre est le cœur du produit. Chaque salarié a un espace documentaire nominatif.

## Déposés par l'entreprise

Exemples : contrat de travail, avenant, bulletin de salaire, document mutuelle, attestation, document administratif, courrier RH, autre document lié à l'emploi.

Le bulletin de salaire se publie par le module Bulletins. Il apparaît ensuite dans le coffre, classé comme bulletin. Il n'existe pas un second formulaire de dépôt de bulletin dans le coffre général.

## Déposés par le salarié

Exemples : arrêt maladie, justificatif, document administratif, autre document demandé par l'entreprise.

Parcours de dépôt : choisir « Déposer un document », choisir la catégorie, ajouter le fichier, ajouter un commentaire facultatif, valider. Une confirmation s'affiche. Le document entre dans l'historique et devient disponible pour les utilisateurs autorisés de l'entreprise.

## Informations d'un document

Nom, catégorie, date, auteur, propriétaire, type, statut, date de dépôt, date de consultation, historique.

## Actions

Selon les droits : consulter, télécharger, déposer, remplacer, supprimer, transmettre.

## Bulletins de salaire

Catégorie particulière du coffre, classée par année puis par mois.

```
2026
  Septembre
  Août
  Juillet
  Juin

2025
  Décembre
  Novembre
```

Chaque bulletin a une période, une année, une date de mise à disposition, un document et un statut consulté ou non consulté.

Le salarié consulte, télécharge et retrouve ses bulletins par année.

L'employeur dépose, consulte, gère les bulletins et choisit le salarié concerné.
