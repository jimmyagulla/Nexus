# E01 — Entreprise

L'entreprise est le périmètre de gestion. Aucune donnée d'une autre entreprise n'est lisible.

| Story                                    | Priorité | Besoin   |
| :--------------------------------------- | :------- | :------- |
| [E01-US01](../us/E01-US01-entreprise.md) | 1        | Critique |

Contrat possédé : identité de l'entreprise, calendrier, isolement. Les autres stories portent l'entreprise. Elles ne créent pas un second périmètre.

Hors epic : les réglages d'un module (types de congé, catégories de frais, types de frais professionnels) appartiennent à la story de ce module et se rangent dans Paramètres sans changer le calendrier.
