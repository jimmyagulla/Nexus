# E03 — Salariés

Un salarié est une fiche dans une entreprise, puis un compte personnel. L'employeur administre la fiche. Il ne prend pas la session du salarié.

Contrat possédé : fiche minimale consommée par les autres modules. Champs : identité, poste, service, contrat, dates, statut Actif ou Inactif, photo, dernière activité.

Les coordonnées modifiables par le salarié sont précisées par E09-US01. E03 les affiche. E03 ne décide pas lesquelles le salarié peut changer.
